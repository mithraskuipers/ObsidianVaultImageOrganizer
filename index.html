Repair

Searches the entire vault for any image a note references but can't find at the expected location, and fixes messy path syntax. Markdown files are never destroyed - see the safety notes below.

How this stays safe:
  • Every note is backed up to .vault-organizer-backups/ before any change is written.
  • A write is refused outright if the result would be empty or less than half the original size - a note can never be wiped out by this tool.
  • Deterministic fixes (image found elsewhere in the vault by exact filename, or just a path-syntax cleanup) are pre-ticked, but you can untick any of them before applying.
  • Fuzzy "possible match" suggestions are never applied automatically - you must tick the box and confirm the right candidate yourself.

Consolidate

Copies every referenced image into an attachments/ folder next to its note, and rewrites references to ![[attachments/filename.ext]].

This modifies your vault.
  • An attachments/ folder is created next to every note that needs one.
  • Images are copied, not moved - originals are left in place.
  • Every local image reference is rewritten to the wiki-link form.
  • Broken references (image not found anywhere in the vault) are skipped and reported, never guessed at.
  • Every note is backed up before being rewritten, and a write is refused if it would shrink or empty the note.
You'll be asked to confirm before anything is written. Recommended order: Audit → Repair → Consolidate → Audit → Cleanup.
